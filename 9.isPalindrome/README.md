# [9. Palindrome Number](https://leetcode.com/problems/palindrome-number/)

**Difficulty:** Easy

**Topics:** Math

## Problem

Given an integer `x`, return `true` if `x` is a **palindrome**, and `false` otherwise.

## Examples

### Example 1

```text
Input: x = 121
Output: true
```

### Example 2

```text
Input: x = -121
Output: false
```

### Example 3

```text
Input: x = 10
Output: false
```

## Constraints

* `-2^31 <= x <= 2^31 - 1`

## Follow-up

Could you solve it **without converting the integer to a string**?
