# [1134. Armstrong Number](https://leetcode.com/problems/armstrong-number/description/)

**Difficulty:** Easy

**Topics:** Math

## Problem

Given an integer `n`, return `true` if `n` is an **Armstrong number**, and `false` otherwise.

An Armstrong number is an integer such that the sum of its own digits, each raised to the power of the number of digits, is equal to the number itself.

## Examples

### Example 1

```text
Input: n = 153
Output: true

Explanation:
153 = 1³ + 5³ + 3³
153 = 1 + 125 + 27
153 = 153
```

### Example 2

```text
Input: n = 123
Output: false

Explanation:
123 ≠ 1³ + 2³ + 3³
```

## Constraints

* `1 <= n <= 10^8`
